# PX4-Auction-Multi-UAV-Scheduler
PX4 Otopilot ve MAVSDK tabanlı, açık artırma/ihale algoritması ile otonom çoklu İHA görev dağılım ve uçuş simülasyonu. Batarya seviyeleri, uçuş mesafesi ve görev ödüllerine göre en uygun drone'u seçer; Gazebo ortamında otonom kalkış, hedefe yönelim, RTL ve iniş görevlerini simüle edip istatistiksel CSV verileri üretir.
